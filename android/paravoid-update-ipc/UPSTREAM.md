# Paravoid update IPC source

This module contains the unchanged update IPC contract from Paravoid revision
`32461c8336325c3381e089193ed77246c5fb90a0`, directory `paravoid-update-ipc/src/main`.
It builds the shared AIDL contract locally so a Store checkout does not require
a sibling Maven repository. Keep package names and transaction definitions compatible
with upstream. Review source licensing before public redistribution as part of
the product publication milestone.
